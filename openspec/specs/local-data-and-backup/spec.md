# local-data-and-backup Specification

## Purpose
为单电脑离线使用场景提供可持久化、可恢复、可导出的本地业务数据，并保留关键资金、排班和恢复操作的审计记录。
## Requirements
### Requirement: 本地数据持久化与一致性

系统 SHALL 将 V2 商品、客户、订单、订单商品、履约、工作安排、质检、工资结算、财务流水、售后、设置和审计记录持久化到独立 V2 本机数据存储中。涉及多项 V2 业务记录的写入 MUST 以原子方式完成，失败时不得留下部分业务结果，也不得写入或修改 V1 业务数据。

#### Scenario: 创建 V2 订单时写入相关记录

- **WHEN** 管理员保存包含客户、多个订单商品、初始确认金额和初始备注的 V2 订单
- **THEN** 系统保存完整 V2 订单关系，或在任一写入失败时不保存该订单的任何部分

#### Scenario: 创建订单时写入相关记录

- **WHEN** 管理员保存包含客户、多个订单商品和初始备注的新订单
- **THEN** 系统保存完整订单关系，或在任一写入失败时不保存该订单的任何部分

### Requirement: 业务附件关联

系统 SHALL 允许 V2 订单资金流水关联 V2 本机凭证附件，并 MUST 在 V2 备份和恢复中保留附件与业务记录的关联。V2 附件不得写入 V1 附件目录。

#### Scenario: 为 V2 收款添加凭证

- **WHEN** 管理员为一笔 V2 收款选择本机凭证文件并保存
- **THEN** 系统将受控副本或索引保存到 V2 附件空间，并在该收款流水中显示凭证

#### Scenario: 为收款添加凭证

- **WHEN** 管理员为一笔收款选择本机凭证文件并保存
- **THEN** 系统保存该附件的受控副本或索引，并在订单流水中显示该凭证

### Requirement: 备份与恢复

系统 SHALL 支持创建包含 V2 业务数据和 V2 附件索引的本地备份。恢复操作 MUST 在覆盖当前 V2 数据前创建当前 V2 数据备份并要求二次确认，且不得覆盖 V1 数据库或其附件。

#### Scenario: 恢复已有 V2 备份

- **WHEN** 管理员选择一个有效 V2 备份包并确认恢复
- **THEN** 系统先备份当前 V2 数据，再恢复该 V2 备份中的数据和附件关联，V1 数据保持不变

#### Scenario: 创建手动备份

- **WHEN** 管理员执行立即备份
- **THEN** 系统生成可识别创建时间的备份包，并记录备份结果

#### Scenario: 恢复已有备份

- **WHEN** 管理员选择一个有效备份包并确认恢复
- **THEN** 系统先备份当前数据，再恢复备份包中的数据和附件关联

### Requirement: 业务导出

系统 SHALL 支持将订单、商品、兼职人员和收付款记录导出为可离线查阅的表格文件，并 MUST 支持按日期或状态筛选导出范围。

#### Scenario: 导出待收款订单

- **WHEN** 管理员筛选待收金额大于零的订单并执行导出
- **THEN** 系统生成仅包含匹配订单及其应收、已收净额和待收金额的导出文件

### Requirement: 关键操作审计

系统 MUST 为 V2 订单资金新增与冲正、订单金额调整、订单内容变更、发货记录、备份和恢复保存操作时间、操作类型、关联对象和操作前后摘要。

#### Scenario: 新增订单金额调整

- **WHEN** 管理员为订单保存一笔金额调整
- **THEN** 系统保存该调整及其关联订单的审计记录，并包含调整前后订单金额摘要

#### Scenario: 确认超产能排班

- **WHEN** 管理员确认保存一个模具产能超出风险的排班
- **THEN** 系统保存排班风险确认记录及其关联的排班和订单商品信息
