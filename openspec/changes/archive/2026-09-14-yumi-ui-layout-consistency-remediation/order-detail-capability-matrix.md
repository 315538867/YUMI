## 结论

1. 订单详情六个 Tab 与优惠、缝边、发货清单快照下载、商品工序、公式设置入口均真实存在且有自动化证据。
2. 概览不再重复发货记录批次表；发货能力完整保留在「发货」Tab（6.4）。
3. 运费承担方是既有后端能力缺口，不属于本变更的视觉回归，也不得标记为视觉任务已完成。
