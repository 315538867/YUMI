## Purpose

为 YUMI renderer 提供统一且可验证的视觉基础，使颜色、排版、空间、密度、动效、浮层和 CSS 依赖顺序不再由单个页面或组件自行决定。

## ADDED Requirements

### Requirement: 共享视觉值通过语义令牌提供

系统 SHALL 通过统一语义令牌提供颜色、排版、间距、尺寸、圆角、阴影、动效和层级。业务页面 MUST 使用语义令牌或经批准的领域固有尺寸，不得新增通用视觉裸值；状态不得只通过颜色表达。

#### Scenario: 页面需要新的共享颜色

- **WHEN** 页面需要一种可跨组件复用的颜色
- **THEN** 系统先定义具有明确语义的共享令牌再由页面消费
- **AND** 页面样式中不直接新增十六进制、RGB、HSL 或渐变值

#### Scenario: 领域布局需要固有尺寸

- **WHEN** 日历轨道、人员色标或任务块需要业务固有尺寸
- **THEN** 系统以具有业务含义的局部变量表达该尺寸
- **AND** 该变量不得替代通用间距、控件高度或颜色令牌

### Requirement: Renderer 使用唯一且有序的样式入口

系统 MUST 通过一个 renderer 样式入口加载第三方样式、Foundations、Primitives、Composites、Patterns 和 Domains，并保持固定覆盖顺序。领域样式不得覆盖共享组件内部结构，未分层的第三方规则不得绕过既定级联顺序。

#### Scenario: 应用加载完整样式

- **WHEN** renderer 启动并加载 UI 样式
- **THEN** 所有本地 UI 样式通过唯一入口加载
- **AND** 第三方样式位于受控层级中，不会无条件压过本地组件契约

#### Scenario: 领域页面增加布局规则

- **WHEN** 领域页面为业务固有几何增加样式
- **THEN** 该规则只能影响领域拥有的节点
- **AND** 不覆盖 Primitive 或 Composite 的内部 class

### Requirement: 页面密度覆盖普通内容与浮层内容

系统 SHALL 提供 compact、standard 和 comfortable 三档密度，并由顶层页面模式决定当前密度。普通内容和通过 Portal 呈现的对话框、抽屉、弹出选择及菜单 MUST 获得一致的密度语义；页面内部区块不得自行制造另一套密度。

#### Scenario: 紧凑页面打开选择浮层

- **WHEN** compact 页面中的负责人打开通过 Portal 渲染的选择浮层
- **THEN** 浮层内容使用 compact 对应的控件尺寸和空间令牌
- **AND** 浮层不因脱离页面 DOM 子树而回退到其他密度

#### Scenario: 独立渲染共享组件

- **WHEN** 共享组件在没有页面模式的测试或独立环境中渲染
- **THEN** 系统使用组件契约规定的默认密度
- **AND** 仅在组件契约允许时接受显式密度覆盖

### Requirement: 浮层层级和动效保持可预测

系统 MUST 使用命名层级保持页面内容、固定操作、菜单/弹出层、遮罩、对话框/抽屉和通知的稳定前后关系。系统 SHALL 尊重减少动态效果的系统偏好，不得以装饰性动画延迟负责人完成操作。

#### Scenario: 对话框上显示结果通知

- **WHEN** 对话框操作完成并产生全局通知
- **THEN** 通知显示在对话框之上且不被遮罩隐藏
- **AND** 页面内容不会越过遮罩或对话框显示

#### Scenario: 系统要求减少动态效果

- **WHEN** 操作系统启用 reduced motion
- **THEN** 系统关闭非必要动画并将必要状态过渡缩短到近乎即时

### Requirement: UI 治理采用渐进式零违规门禁

系统 SHALL 记录既有裸值、旧 class、私有断点和未消费令牌的逐文件基线，并在迁移期间禁止新增或扩大违规。已迁移层和页面家族 MUST 立即清零并锁定违规；全部迁移完成后 MUST 启用仓库级严格门禁。

#### Scenario: 未迁移页面保持现状

- **WHEN** P0 后的改动触及尚未迁移的页面
- **THEN** 自动治理允许已登记的既有违规继续存在
- **AND** 拒绝新增违规文件、规则类别或违规位置

#### Scenario: 页面家族完成迁移

- **WHEN** 一个页面家族完成视觉和功能验收
- **THEN** 该页面家族的旧 class、私有断点和通用视觉裸值全部清零
- **AND** 后续改动不得重新引入这些违规
