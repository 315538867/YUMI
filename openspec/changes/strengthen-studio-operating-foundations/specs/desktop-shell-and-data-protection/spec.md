## Purpose

让负责人在内容较长、数据逐步积累的桌面应用中保持稳定导航，并能从设置内可靠地创建、查看和确认恢复本地数据备份。

## ADDED Requirements

### Requirement: 固定桌面应用导航外壳
系统 MUST 在桌面视口内固定显示左侧导航和顶部栏，并让右侧内容工作区承担主要纵向滚动。内容过长 MUST NOT 撑高或带动左侧导航滚出视口；导航本身在窗口高度不足时可以独立滚动。

#### Scenario: 浏览长内容页面
- **WHEN** 负责人在右侧打开内容高度超过窗口的页面并向下滚动
- **THEN** 左侧导航和顶部栏仍保持可见，且只有右侧内容区域滚动

### Requirement: 从设置创建和查看本地备份
系统 MUST 在设置的数据保护模式中展示最近备份状态、立即备份操作和备份历史。创建成功后，最新备份 MUST 出现在历史中并展示创建时间、原因、应用版本和附件数量。

#### Scenario: 手动创建备份
- **WHEN** 负责人在数据保护模式点击“立即备份”
- **THEN** 系统创建一份手动备份并刷新备份历史

### Requirement: 受确认保护的备份恢复
系统 MUST 仅在负责人明确确认后恢复指定备份。恢复确认界面 MUST 明确说明恢复前将创建安全备份，且恢复完成后应用将重启；取消确认 MUST 不触发恢复。

#### Scenario: 取消恢复
- **WHEN** 负责人打开某个备份的恢复确认并取消
- **THEN** 系统不恢复任何文件或数据库

#### Scenario: 确认恢复
- **WHEN** 负责人确认恢复指定备份
- **THEN** 系统先创建恢复前安全备份，再恢复指定备份并按既有恢复流程重启应用
