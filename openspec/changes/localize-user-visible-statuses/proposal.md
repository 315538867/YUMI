# 用户可见状态中文化提案

- 提案名称：用户可见状态中文化
- Change ID：`localize-user-visible-statuses`
- 方案版本：v1.0
- 状态：已完成
- 创建人：Codex
- 创建时间：2026-09-06
- 最后修改时间：2026-09-06

## Why

当前应用的数据库和接口以英文枚举保存订单生产状态、收付款状态及排班状态。部分界面直接渲染或在映射缺失时回显原始枚举，导致列表和详情中出现英文状态，影响中文工作流的可读性与一致性。

## What Changes

- 建立集中式的状态展示契约，为生产、收付款和排班状态提供统一的中文名称与状态色。
- 将订单列表、订单详情、报表、概览、排班日历、排班详情与状态下拉框等所有用户可见状态统一改为使用展示契约。
- 对未识别的历史或未来状态值提供中文兜底文案，并保留原始值用于辨识；界面不得直接裸露英文枚举。
- 保持数据库值、共享 IPC 契约和服务层业务判断使用现有英文枚举，不迁移历史数据，不改变状态流转规则。
- 增加状态展示的单元及界面回归测试，覆盖全部已知状态、未知状态兜底和关键界面使用点。

## Capabilities

### New Capabilities

- `user-visible-status-localization`：所有面向用户的状态值均使用统一中文展示，并保证未知状态不会直接暴露英文内部枚举。

### Modified Capabilities

- 无。

## Impact

- 受影响代码：`src/renderer/pages/app.tsx`、新增或调整的渲染层状态展示工具与对应测试。
- 数据、数据库迁移、共享接口和主进程服务不变；不新增第三方依赖。
- 订单、报表及排班相关界面将统一使用同一展示映射，避免后续页面遗漏。
