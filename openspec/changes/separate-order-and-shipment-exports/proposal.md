# 提案：订单表与发货清单分离导出

- Change ID：`separate-order-and-shipment-exports`
- 方案来源：`docs/solutions/2026-09-06-separate-order-and-shipment-exports-solution.md` v2.0
- 状态：第 2 阶段实现与自动化验证已完成，等待已解锁桌面会话中的人工保存验收
- 最后更新：2026-09-06

## 为什么

第 1 阶段已分离订单表和单次发货清单的保存入口，但导出内容仍是基础字段表格，无法满足客户确认和发货签收所需的正式单据样式。用户提供了订单表与发货清单样例，并确认两个单据都应嵌入产品图片、采用完整表格样式；同时明确发货清单应展示订单全部商品、采购总数量、本次发货数量和未发货数量。

## 变更内容

- 引入 ExcelJS 构建具备样式、合并单元格、打印设置和图片嵌入能力的订单表、发货清单。
- 订单表改为客户信息、`下单表：YYYY.MM.DD` 标题、报价构成、图片明细和合计行。
- 发货清单改为客户/发货总数、全订单商品、采购总数量/本次发货数量/未发货数量、合计及发货页尾信息。
- 保持既有独立保存入口、IPC、文件命名和不写入业务数据的边界不变。

## 影响

- 受影响实现：`package.json`、`package-lock.json`、`src/main/services/studio-service.ts`、新增工作簿构建模块、服务层测试。
- 不影响：共享 API 契约、IPC/预加载桥接、订单详情按钮、订单/发货记录数据模型和已有发货保存流程。
- 风险：产品图片文件不可用时单元格留空；ExcelJS 替换仅限这两份单据，不迁移其他 SheetJS 报表。
