## Purpose

让订单确认文件与单次发货凭证分别对应明确业务事实，并以可直接发送、打印、签收的成品 XLSX 版式呈现客户信息、商品图与必要的数量信息。

## ADDED Requirements

### Requirement: 独立保存带版式的订单确认表

系统 SHALL 允许管理员从任一已保存订单单独保存订单确认表。生成的 XLSX MUST 只包含一个名为“订单表”的工作表，标题 MUST 为 `下单表：YYYY.MM.DD` 且日期取订单创建日期。订单表 MUST 在顶部展示客户名称、联系方式与收货地址，并以 `序号、产品图、产品名称、产品克重、理望单价、包装费、替换袋、总单价、订购数量、总金额、备注` 列展示每个订单商品。产品有可读取图片时 MUST 嵌入图片；无图片或图片不可读取时 MUST 留空并继续导出。总单价 MUST 为理望单价、包装费与替换袋之和，总金额 MUST 为总单价乘订购数量；文件末尾 MUST 汇总订购数量与总金额。订单表 MUST 使用黄色表头、边框、金额格式和面向打印的横向页面设置。

#### Scenario: 有产品图片的订单保存订单确认表

- **WHEN** 管理员为含两种有图片商品的订单选择生成订单表
- **THEN** 系统保存仅含“订单表”的工作簿
- **AND** 标题、客户信息、两个图片、明细价格计算及合计均符合订单确认表版式

#### Scenario: 产品无可用图片的订单保存订单确认表

- **WHEN** 订单中某商品没有图片或图片文件已不可读取
- **THEN** 系统仍保存订单表
- **AND** 该商品的产品图单元格为空，其他明细与合计完整

### Requirement: 按已保存发货记录保存全订单视图发货清单

系统 SHALL 在每条已保存发货记录上提供独立的“保存发货清单”操作。系统 MUST 使用该记录归属订单的全部订单商品生成独立 XLSX，工作表名 MUST 为“发货清单”，标题 MUST 为该记录发货日期对应的 `M. D发货清单`。发货清单顶部 MUST 显示客户名称与本次发货总数，明细列 MUST 为 `序号、产品图、产品名称、采购总数量、本次发货数量、未发货数量、备注`。采购总数量 MUST 等于订单商品数量；本次发货数量仅等于所选发货记录对应商品数量，未包含的商品 MUST 为 0；未发货数量 MUST 基于导出时该订单全部已保存发货记录的累计数量。文件 MUST 含三类数量合计、发货时间、收货人和该次发货备注，并采用带图片与边框的打印版式。

#### Scenario: 保存部分商品的发货清单

- **WHEN** 一笔订单有两个商品，但某条已保存发货记录仅包含其中一个商品 2 件
- **THEN** 管理员从该条记录选择保存发货清单时，系统保存仅有“发货清单”的工作簿
- **AND** 两个订单商品均在清单中
- **AND** 未发商品的本次发货数量为 0，两个商品的未发货数量均按当前累计发货量正确计算

#### Scenario: 重新保存历史发货清单

- **WHEN** 管理员从历史发货记录选择保存发货清单
- **THEN** 系统使用该历史记录的发货日期、备注和商品数量生成文件
- **AND** 导出不得新增、修改或删除订单、商品和发货记录

### Requirement: 分离导出操作与文件命名

系统 MUST 将订单表与发货清单作为两个独立保存操作呈现，并以可区分的保存窗口标题和默认文件名标识文件类型。订单表默认文件名 MUST 包含订单编号；发货清单默认文件名 MUST 包含订单编号与所选发货记录的发货日期。取消任一保存窗口时，系统不得写入业务数据。

#### Scenario: 取消保存发货清单

- **WHEN** 管理员点击某条发货记录的保存发货清单后取消保存窗口
- **THEN** 系统不生成目标文件
- **AND** 订单和发货记录的数量与内容保持不变
