# 全局默认兼职时薪提案

- 提案名称：全局默认兼职时薪
- Change ID：`global-default-worker-hourly-wage`
- 方案版本：v1.0
- 状态：已完成
- 创建人：Codex
- 创建时间：2026-09-06
- 最后修改时间：2026-09-06

## Why

商品录入和商品详情的成本预估目前需要临时输入时薪，新建商品甚至默认以 0 计算；订单预计成本也没有采用统一的人工成本口径。兼职人员个人时薪已用于实际结算，但不能替代商品报价所需的标准预计人工成本。

## What Changes

- 在版本化系统成本设置中新增默认兼职时薪，并在设置页面提供维护入口。
- 商品新建和商品详情的成本预估自动采用全局默认兼职时薪，移除临时预估时薪输入，并显示实际采用的标准时薪。
- 订单商品快照保存创建或更新时的默认兼职时薪，预计成本包含该人工成本，后续修改全局设置不回算历史订单。
- 保持兼职人员个人时薪和实际制作成本结算逻辑不变，实际成本仍按实际人员时薪历史计算。

- 不新增第三方依赖；不修改兼职人员实际时薪与生产结算规则。
