# YUMI 桌面工作区底色分区优化方案

## 1. 已确认的设计方向

采用“柔和底色分区”方案：收紧工作区内板块的留白，取消常规业务模块外框和阴影，以暖白、浅暖灰及极浅语义色块建立层级。整体保持简约、安静、偏桌面工具的 Linear 式秩序感，不做网页后台式大卡片堆叠。

## 2. 视觉规则

| 场景 | 调整后规则 |
| --- | --- |
| 页面工作区 | 外层使用暖灰底色；内容内边距收紧为 22px × 28px，降低页面空旷感。 |
| 概览统计 | 默认统计项仅以浅色底区分，卡片之间使用 10px 间距；预警、风险项改为低饱和淡杏色与淡红色底，不使用顶部色线。 |
| 常规业务板块 | `.panel`、表单分段、报表筛选、待办队列等不使用 1px 外框或投影；通过比页面更亮或稍深的底色、8px 圆角与紧凑间距分组。 |
| 表格与日历 | 保留表格行分隔线、日历网格线、输入控件边界和键盘焦点轮廓；这些属于操作定位与可用性线索，不当作业务板块外框。 |
| 交互与状态 | Hover、选中、完成、风险继续依靠底色及文字颜色；不会删除 focus-visible 轮廓。 |

## 3. 影响范围

- 概览及报表的统计区、常规面板和待办队列。
- 订单、商品、排班检查器中的表单分段、汇总区、详情列表外层。
- 不修改业务数据、表单字段、日历排班逻辑、表格列和导航结构。

## 4. 验收标准

1. 常规业务板块不再以外框或阴影作为主要分组手段。
2. 内容区、统计区和主要面板之间的间距比现状更紧凑，且不会影响阅读和操作点击。
3. 风险与预警仍可一眼识别，但以语义底色而不是边框色线表达。
4. 表格、日历、输入控件和键盘焦点仍保留必要的边界与可访问性反馈。
