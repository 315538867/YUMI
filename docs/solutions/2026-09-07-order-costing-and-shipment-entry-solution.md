# 订单完整成本、单任务排班与发货弹窗方案

- **方案版本**：v1.0
- **设计时间**：2026-09-07
- **最后修改时间**：2026-09-07
- **修改人**：Codex
- **对应 OpenSpec 变更**：`refine-order-costing-and-shipment-entry`
- **方案状态**：已实施

## 适用范围

商品成本维护、订单预计与实际成本、排班任务归属、兼职人员初始时薪，以及订单详情中的成本和发货交互。

## 已确认业务口径

1. 预计成本为：胶水、包装、配件、替换袋、捏毛装袋、缝边成本、预计人工和提成之和。
2. 预计人工使用订单创建时的默认时薪：`订单数量 × 单件标准制作分钟 ÷ 60 × 默认时薪`。
3. 实际成本包含与预计成本相同的全部成本项；只有人工来源不同：`已完成排班的任务基础分钟 + 额外预留分钟`，按该排班兼职人员在当日生效的时薪计算。
4. 缝边是客户可选的增值服务。缝边单价为客户售价，计入订单应收；商品另维护缝边成本，计入订单成本。启用缝边后数量等于订单商品数量，不允许手工填写。
5. 每次排班只允许一个订单的一种商品，使排班完整预留时间唯一归属到该订单商品。
6. 商品增加“捏毛装袋（元/个）”；新建兼职人员的时薪默认带入系统默认时薪，创建时允许修改。
7. 订单详情不直接展示成本；通过成本详情弹窗查看。发货区域仅展示汇总和历史，点击“新增发货”弹窗填写；历史发货只读并可导出。

## 技术设计

- 商品表增加 `fluff_packing_cost_cents` 和 `edge_cost_cents`，迁移默认 0；商品快照同步扩展，旧 JSON 缺失字段读取为 0。
- 成本领域计算器返回每个成本项目和总额。订单创建时用订单快照计算预计成本；订单实际成本使用订单数量的非人工项目与已完成排班的人工项目汇总。
- 新建/编辑订单服务端归一化缝边数量，避免仅靠前端限制导致金额与成本不一致。
- 排班预览、保存与更新要求恰好一项任务；完成排班时以该排班完整预留分钟结算人工并刷新订单实际成本。
- 成本弹窗获得按订单商品的预计/实际项明细；报表继续读取同步后的订单实际成本总额。
- 发货创建仍走现有 IPC 和校验，UI 将表单移至显式弹窗；历史编辑操作从界面移除。

## 验收标准

- 商品可维护捏毛装袋、缝边成本，后续订单成本预览和订单快照正确包含两项。
- 启用缝边时数量自动跟随订单商品数量，缝边售价进入应收、缝边成本进入成本。
- 成本详情弹窗显示完整预计与实际成本明细；订单详情主页面不展示成本数字。
- 一个已完成的单任务排班，其任务基础分钟与额外预留分钟均计入实际人工；实际成本不再长期为 0。
- 新建和编辑排班不能保存多任务；新建兼职人员默认显示系统默认时薪。
- 发货输入仅在新增发货弹窗中出现，历史发货不显示编辑入口。
